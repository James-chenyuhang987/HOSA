# 诊途

诊途是一个面向跨方言就医沟通的 HOSA 参赛原型，帮助普通话使用者与粤语、闽南语、上海话、四川话或东北话使用者双向沟通，并提供文字、读法、语音输入和沟通提示。

## 当前功能

- **双向方言翻译**：在普通话与粤语、闽南语、上海话、四川话、东北话之间切换，获得常用表达的文字与读法。
- **就诊沟通短句**：内置挂号、分诊、急诊、科室问路、症状时间、检查/验血、空腹、用药、过敏、怀孕、轮椅、医保、住院、复诊、费用和书面说明等高频表达。
- **语音输入翻译**：点击输入框旁的麦克风，用普通话或当前方言录入一句话，识别文字会自动进入翻译结果。
- **译文复制与提示**：方便把译文交给对方阅读，并提示重要医疗信息需要再次确认。
- **医院地图**：独立入口提供院区与楼层示意，支持点选门诊楼、住院楼、检查楼和急诊楼，搜索科室或服务点，并查看通行设施。地图使用本地演示数据，不代表真实医院布局，不提供实时定位。

语音识别使用浏览器原生 `SpeechRecognition` 能力。Chrome、Edge 等浏览器支持较好，其他浏览器可能需要直接输入文字。粤语会优先请求 `zh-HK` 识别；闽南语、上海话、四川话和东北话暂使用普通话识别模型，方言口音可能影响结果。浏览器会请求麦克风权限，应用不会保存或主动上传音频；浏览器是否将语音交给其识别服务商处理，取决于浏览器实现和隐私政策。请先等界面显示“麦克风已打开”再开始说话；短暂静音或识别服务提前结束时，页面会自动短暂重连，并尽量保留已经听到的文字。结束录音时如果浏览器迟迟不返回结束事件，界面会提供“立即结束”兜底按钮。

翻译结果用于辅助沟通，不替代专业口译、医疗判断或医院官方信息。四川话和东北话等方言存在明显的地区差异，界面会区分“常用短句”“词语参考”和“待本地确认”；涉及用药、剂量和检查安排时，请让医护人员复述确认。

没有完整收录的普通句子也会尝试按常见词语和句式生成方言参考表达，并标记为“词语参考”。这类结果适合辅助沟通，遇到诊断、用药和检查安排时仍应让医护人员再次确认。

## 技术栈

- **前端框架**：React 19 + React DOM
- **开发语言**：TypeScript
- **构建工具**：Vite
- **界面样式**：原生 CSS，包含响应式布局、暖色纸张质感和 CSS 动画
- **语音识别**：浏览器原生 Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`）
- **翻译逻辑**：前端本地词库、医院场景短句、词语映射和常用句式替换
- **测试工具**：Vitest + Testing Library + jsdom
- **代码检查**：Oxlint
- **部署方式**：GitHub Actions 构建后发布到 GitHub Pages

### 实现说明

- 应用是纯前端页面，目前没有后端服务、数据库或第三方运行时翻译依赖。
- 语音录音只在当前页面临时转换为文字，不生成、不保存音频文件，也不会由应用主动上传音频。
- Web Speech API 是否把语音交给浏览器或其识别服务商处理，由浏览器实现和对应隐私政策决定。
- 粤语识别优先使用 `zh-HK`；闽南语、上海话、四川话和东北话使用 `zh-CN` 作为兼容回退，因此结果可能按普通话口音识别。
- 词库和翻译规则位于前端代码中，识别文本会复用同一套翻译逻辑；用户可以在翻译前编辑识别结果。
- 地图使用原生 SVG、CSS 与 React 交互实现，不依赖在线地图服务。建筑与楼层数据位于 `src/hospitalMapData.ts`；接入真实医院时需要用院方确认的地图资料替换演示数据。

## GitHub Pages 部署

合并到 `main` 后，GitHub Actions 会自动构建并发布网站：

<https://james-chenyuhang987.github.io/HOSA/>

首次部署前，请在仓库的 **Settings > Pages > Build and deployment** 中将 **Source**
设置为 **GitHub Actions**。之后每次推送到 `main` 都会自动更新网页，也可以在
**Actions > Deploy to GitHub Pages** 中手动运行。
